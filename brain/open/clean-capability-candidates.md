# Clean capability candidates

These are product directions suggested by reviewed source capability maps. They are not imported apps and none should be treated as approved automatically.

## High-confidence next improvements

- **Signal Board:** a compact, local overview of active NovaShell modules, workflow state, source review status, and useful system links.
- **Knowledge annotations:** owner-authored tags and short notes attached to Second Brain entries, stored locally and never automatically sent to a model.
- **Loop Lab markers:** named local loop presets and saved session notes for a user-selected track.
- **Weather detail cards:** forecast confidence, daylight, wind, and alerts with a clear data-source state.

## Needs a separate review first

- Financial watchlists: data source, delay, and no-trading language.
- Sports and route discovery: provider terms, attribution, and data freshness.
- Accessibility places: completeness and safety disclaimers.
- Any code reuse: ownership, license, security, and removal plan.

## Never an intake shortcut

Personal communication, private records, accounts, keys, uploads, databases, logs, and production backups are excluded even if they are present in an owner-provided source.
