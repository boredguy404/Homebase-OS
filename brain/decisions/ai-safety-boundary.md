# Relay is reviewable before it is powerful

Relay can explain approved local information and navigate named NovaShell views
without an AI key. With an optional local provider, it can draft responses and
removable user apps. It cannot silently run commands or modify the core app.

Core edits are limited to a small allowlist, require explicit review and typed
confirmation, and make a local backup first. Imported Brain material is
read-only context; it never expands Relay’s authority.
