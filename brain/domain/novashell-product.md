# NovaShell product vocabulary

- **NovaShell** is a local-first control layer, not a replacement operating system.
- **Pocket Archive** is the private shelf for games the owner adds themselves.
- **My Library** is the local file surface, restricted to the owner’s home folder.
- **Orbit** is the persistent radio and local-audio player.
- **Relay** is the visible local guide and optional AI drafting surface.
- **Utility Desk** is for small offline-capable daily tools and the local Project Board.

Use these names consistently. A user should always know whether an action stays in NovaShell, opens a local program, or visits a website.
