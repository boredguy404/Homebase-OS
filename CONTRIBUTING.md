# Contributing to Homebase

Homebase is meant to become a great community-built product. Bug reports, design ideas, documentation improvements, accessibility work, platform support, and focused pull requests are all welcome.

## Before opening a pull request

1. Open or join an issue for substantial changes so the direction is clear.
2. Keep private files out of commits: no ROMs, BIOS files, saves, credentials, personal media, or copyrighted game artwork.
3. Test touch, mouse, keyboard, and controller navigation where the change applies.
4. Keep the lightweight Chromebook experience in mind.
5. Explain what changed, why it helps, and how it was tested.
